🚀 About the Sprint

Python Winter Sprint 2026 is a peer-led, practice-first learning initiative designed to help students build real Python skills through daily tasks, structured tracks, and GitHub-based submissions.

This sprint is not about rushing to complete code. It is about learning how to think, build, and document properly — the way real developers do.

🎯 Agenda & Philosophy

  • Learn Python by doing, not watching
  • Build consistency over 14 days
  • Maintain verifiable proof of work on GitHub
  • Focus on logic, structure, and clarity
  • No pressure, no competition — learning comes first
"Upload whatever day's task you solve. Missing a day is fine. Not learning is not."

🧭 Learning Tracks

The sprint runs under three structured learning tracks. Choose the one that fits your current level.

🔵 Project Track

For students with strong Python command who want industry-grade projects

  • Daily project-grade PDFs
  • Complete project instructions
  • Expected behaviour & sample outputs
  • Replicate the sample run correctly

Outcome: 6-7 solid, project-grade projects on GitHub

🟡 Core Track

For students following from Day 1, no longer beginners

  • Know variables, data types, strings
  • Comfortable with if/else and loops
  • More challenging logic problems
  • Can attempt Project Track if confident

Focus: Consistency is the key

🟢 Foundation Track

For complete beginners, just starting Python

  • Page 1 of every PDF
  • Daily topic with learning resources
  • Practice examples first
  • Then solve the Foundation question

⚠️ Important: Don't binge-watch! Code alongside the video.
